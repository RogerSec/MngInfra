# MngInfra
> Manage (IT/OT) Infrastructure

## Why?
> As the owner of a small homelab and network, I have the challenge of knowing all of the assets I currently have deployed, what softwares they are running and how they are configured.
> This project aims to replace various paper notes I have spread across these assets that I must rely on everytime I need/want to change something.


## Project Objective
> Have a simple tool that I can use to manage my IT/OT assets
> Dive deeper into the Rust programming language

## Project Restraints
* Wherever possible Rust must be used as the programming language choice
* Minimal use of dependencies/rust packages - the aim is to have a standalone application that doesnt need other projects to operate
* Absolutelly no AI generated code
